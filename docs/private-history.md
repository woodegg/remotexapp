# Historical Release and Issue Records

This public repository starts from a reviewed source snapshot. Earlier
operational issues, workflow logs, and release artifacts remain in a separate
private archive and are not mirrored here. Historical design and test records
may mention their version or issue numbers for context; those references are
not links to public artifacts.

Use the public repository's own Releases, Issues, and Actions pages for work
created after this snapshot. Do not infer a deployed environment's version from
historical records; query the running Manager and verify its release checksum.
