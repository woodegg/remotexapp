# Integration guide moved

Use [Host application migration for App Package ABI v1](host-app-package-migration.md).
The generic guide replaces downstream-specific operational instructions.

For Core 0.15 → 0.16 native SDK adaptation, use the
[native host migration guide](native-host-migration.md). App Package ABI v1
remains supported; native window/recovery/audio/clipboard adaptation is covered
there rather than by the earlier package migration.
